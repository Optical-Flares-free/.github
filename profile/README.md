## 🧠 Overview

Optical Flares is a lens flare generator for After Effects: it builds a flare from editable elements — aperture, streaks, rings, glints and textures — and tracks it to a light or a point in the scene.

On a Windows machine it runs as a plug-in suite that loads inside Adobe After Effects CC 2018 or newer. Typical use is lens flare generator work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🔆 Element Stack | A flare is assembled from aperture, streaks, rings and glints, each editable. |
| 🎨 Aperture Editor | Blade count and shape define the polygonal ghost structure. |
| 🌫️ Streaks and Rings | Anamorphic streaks with chromatic shift and adjustable length. |
| 📌 Light Tracking | Ties the flare to a 3D light or a tracked point in the comp. |
| 🎛️ Preset Browser | Presets cover anamorphic, spherical and practical lens types. |
| 🧩 Blend Modes | Screen, add and overlay modes with per-element opacity. |
